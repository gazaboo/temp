# Projet Git à vocation pédagogique 

## Principaux concepts

### Commandes principales
- git init
- git add
- git commit

### Lier un repo local avec github
- créer des clés ssh
- ajouter les clés ssh au ssh-agent
- mettre la clé public sur github

### Faisons des branches !
- Fais partie du workflow standard en git
- branch early, branch often !
